# 🤖 Instagram Autonomous AI Agent (نسخه ارتقایافته و کاملاً خودمختار)
**ایجنت هوشمند و خودمختار مدیریت اینستاگرام با هسته Instagrapi، تسک‌انجین طبیعی و کنترل ۱۰۰٪ از طریق تلگرام**

این پروژه یک ایجنت خودمختار، ماژولار و بهینه‌شده برای سرورهای لینوکسی کم‌منبع (۲ گیگابایت رم و ۲ گیگابایت فضا) است که بدون نیاز به دستکاری کدهای Python یا ویرایش متغیرها، مستقیماً از طریق **ربات تلگرام** راه‌اندازی، پیکربندی و مدیریت می‌شود.

---

## 🚀 ۱. راه‌اندازی فوق‌ساده فقط با فایل `token.txt`

برای اجرای پروژه روی هر هاست یا VPS، فقط کافیست فایل `token.txt` موجود در پوشه اصلی را باز کنید و **صرفاً دو خط** در آن قرار دهید:

```text
55091234
1234567890:AAF_YOUR_TELEGRAM_BOT_TOKEN_HERE
```
- **خط اول**: شناسه عددی تلگرام ادمین اصلی (`OWNER ID`)
- **خط دوم**: توکن ربات تلگرام دریافتی از `@BotFather` (`BOT TOKEN`)

سپس کل پروژه را اجرا کنید. تمام تنظیمات دیگر (مدل‌های هوش مصنوعی، Session اینستاگرام، اتصال حساب شخصی تلگرام با API ID/HASH، تسک‌ها و پروکسی) مستقیماً از داخل ربات تلگرام دریافت و به صورت رمزنگاری‌شده در پایگاه داده پایدار (`SQLite`) ذخیره می‌شوند.

## ✨ ۲. قابلیت‌های جدید و وضعیت پشتیبانی هر بخش

| قابلیت / ماژول | وضعیت عملکرد | نحوه استفاده در تلگرام |
| :--- | :--- | :--- |
| **۱. راه‌اندازی اولیه با `token.txt`** | **کاملاً فعال ✅** | خواندن خودکار `OWNER ID` و `BOT TOKEN` در لحظه شروع (`config.py`) |
| **۲. راه‌اندازی تعاملی AI در `/start`** | **کاملاً فعال ✅** | دریافت ۴ مرحله‌ای `Base URL`، `API Key`، `Model Name` و تست واقعی اتصال پیش از ثبت |
| **۳. مدیریت چند API و مدل با `/مدل`** | **کاملاً فعال ✅** | افزودن چند سرویس مختلف، تست مجدد، حذف و تغییر مدل فعال کل پروژه در لحظه |
| **۴. موتور ساخت تسک با زبان طبیعی** | **کاملاً فعال ✅** | تبدیل جملات طبیعی (مثلاً «هر ۳۰ ثانیه دایرکت‌ها رو بررسی کن...») به تسک پایدار با تأیید ادمین |
| **۵. دریافت و تبدیل Session اینستاگرام** | **کاملاً فعال ✅** | ارسال فایل `.json` کوکی مرورگر یا Session در تلگرام، تشخیص فرمت، تبدیل به قالب Instagrapi و تست واقعی |
| **۶. اتصال تلگرام با `API ID` و `API HASH`** | **کاملاً فعال ✅** | ویزارد ۵ مرحله‌ای در ربات (API ID، API HASH، شماره تلفن، کد تأیید، رمز دومرحله‌ای 2FA) با Telethon |
| **۷. جست‌وجوی اینترنتی به‌روز (2026+)** | **کاملاً فعال ✅** | جست‌وجوی زنده وب + GitHub API، استخراج تاریخ انتشار صفحه و اعلام صادقانه در صورت قدیمی بودن منابع |
| **۸. نصب پکیج و توسعه با اجازه ادمین** | **کاملاً فعال ✅** | تشخیص نیاز به پکیج، اعلام نسخه و ریسک، نصب ایزوله پس از ارسال کلمه «تأیید» و تهیه بکاپ قبل از تغییر فایل |
| **۹. پیام غنی تلگرام با `<tg-thinking>`** | **کاملاً فعال ✅** | نمایش `Thinking…` کمرنگ با `sendRichMessageDraft` و نهایی‌سازی با `sendRichMessage` (همراه با Fallback خودکار به HTML) |
| **۱۰. آمار Reach / Saves در API خصوصی** | **وابسته به نوع اکانت ⚠️** | در صورت عدم ارائه توسط اینستاگرام، بدون حدس‌زدن مقدار صریح `Unsupported` گزارش می‌شود |

## 🛠 ۳. نصب و اجرا روی VPS لینوکسی یا Docker

### روش اول: اجرای مستقیم در محیط مجازی Python
```bash
sudo apt update && sudo apt install -y python3.11 python3.11-venv python3-pip ffmpeg
cd instagram_ai_agent
python3.11 -m venv .venv
source .venv/bin/activate
pip install --upgrade pip
pip install -r requirements.txt

# قرار دادن OWNER ID در خط اول و BOT TOKEN در خط دوم token.txt
nano token.txt

# اجرای ربات
python main.py
```

### روش دوم: اجرا با Docker (پایدار ۲۴/۷)
```bash
docker build -t instagram-ai-agent .
docker run -d --name ig-agent --restart always \
  -v $(pwd)/token.txt:/app/token.txt \
  -v /tmp/ig_api:/tmp/ig_api \
  -v $(pwd)/data:/app/data \
  -v $(pwd)/logs:/app/logs \
  instagram-ai-agent
```
